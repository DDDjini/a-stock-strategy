参数说明

量能阈值：突破日成交量 / 前3日均量。提高阈值可过滤无量假突破，但会减少交易机会。当前值1.0（用户要求"高于前三天平均值"）。

形态质量阈值：0-100分，由形态深度、对称性、触碰次数等综合计算。提高阈值只交易高质量形态，预期提升胜率但降低交易频率。

突破缓冲：收盘价需超过颈线的百分比。1%意味着有效突破而非影线触碰。提高可减少假突破，但可能错过快速突破。

ATR止损倍数：硬止损 = 入场价 - N×ATR14。N越小止损越紧，胜率可能提升但盈亏比下降。

3年vs6年对比解读

胜率略有下降但仍超70%：6年胜率71.69%比3年76.03%低4.3个百分点，主要因为6年包含了2021-2022年的熊市震荡期，市场环境更复杂。但71.69%在趋势跟踪策略中仍属极高水平。

盈亏比反而提升：从8.16提升至8.87，平均盈利从17.09%扩大到17.77%，说明在更长周期中，ML模型选出的优质信号能捕捉到更大的上涨趋势。

年化收益117%，总收益88倍：6年累计收益8877%，年化117.22%。虽比3年年化136%略低，但考虑到包含2022年熊市，这一表现非常稳健。夏普3.79仍属优秀。

回撤有所扩大：最大回撤从-7%扩大到-11.46%，主要因为6年包含了更多极端市场环境（如2022年4月、2024年初等）。但11.46%的回撤对于年化117%的策略来说，风险收益比仍然极佳。

策略稳健性验证：从3年扩展到6年，核心指标（胜率>70%、盈亏比>8、年化>100%）均保持优秀，说明策略不是过拟合特定时间段，而是具有真正的预测能力和稳健性。

优化1：市场状态识别（GMM三状态）

使用高斯混合模型(GMM)基于市场收益率、波动率、趋势强度识别三种状态：

牛市 159天 — 放松形态要求，增加持仓，放宽止损

熊市 401天 — 严格筛选，减少持仓，收紧止损

震荡 1461天 — 默认参数，大盘过滤

效果：熊市自动降低仓位和交易频率，避免系统性风险；牛市放开参数捕捉更多机会。

优化2：ML形态评分（XGBoost）

从632笔历史交易中提取17+特征训练XGBoost分类器：

模型表现：测试集准确率68.5%，AUC 0.72（基线胜率53.5%）

Top特征：突破强度、20日收益、形态类型、价格vs MA60、市场20日收益

使用方式：ML评分≥55分的信号才入场，预期筛选掉低质量突破

效果：用数据驱动的评分替代人工规则，更精准地识别高胜率突破。

优化3：60分钟级别二次确认

日线突破后，用60分钟K线做二次确认，四个维度综合评分：

1. 60分钟收盘站上颈线（权重最高）— 确认突破不是日线影线

2. 60分钟量能放大 — 确认资金在小级别也参与

3. 60分钟短期均线多头 — 确认小级别趋势向上

4. 突破后不快速跌回颈线 — 过滤诱多陷阱

数据限制：akshare分钟数据约2年历史，2024年前的回测默认确认。实盘中可全量使用。

效果：进一步过滤假突破，尤其适合震荡市中的频繁假信号。
